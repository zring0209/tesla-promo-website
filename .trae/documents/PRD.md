# 产品需求文档（PRD）—— MERIDIAN 落地展示页

## 1. 产品概述
MERIDIAN 是一款面向团队的共享创意画布与协作知识平台，让分散的灵感在同一空间汇聚成型。
- 解决的问题：团队创意散落在多个工具中，缺乏一个"公开可共用"的聚合创作空间
- 目标用户：产品团队、设计工作室、研究小组、内容创作者
- 价值主张：以一张可共享的无限画布，让创意从草稿到共识零摩擦流转

## 4. 用户界面设计

### 4.1 设计风格
- **美学方向**：Editorial Brutalist × Refined Dark —— 编辑式版面骨架 + 粗野主义 oversized 字号，配以精致深色质感
- **主色调**：深炭黑底 `#0E0E0C` + 暖米白前景 `#F2EDE3` + 单一锐利琥珀强调色 `#E8A33D`
- **次要色**：灰阶 `#3A3A36` / `#6B6B63` 用于分隔与次要文本
- **字体**：标题用 Fraunces（可变衬线，表现力强）+ 正文用 Space Grotesk（几何无衬线，现代克制）
- **按钮风格**：主按钮为实心琥珀胶囊带轻微投影；次按钮为描边幽灵按钮
- **布局**：桌面优先 12 列栅格，大量留白与不对称构图，章节间粗水平分隔线
- **装饰细节**：噪点纹理叠层、网格背景、装饰性序号编号（01/02/03）

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|--------|
| 落地页 | Hero 主视觉 | 深色底 + 网格光晕背景、Fraunces 超大标题、双 CTA、入场交错动画 |
| 落地页 | 特性矩阵 | 卡片悬停上浮 + 边框点亮，编号装饰 |

### 4.3 响应式
桌面优先设计；移动端折叠为单列，导航收为汉堡菜单，字号等比缩放，触摸热区 ≥44px。

### 4.4 3D 场景
本页为静态落地页，不使用 3D 场景，以 CSS 动效与排版张力营造视觉冲击。
